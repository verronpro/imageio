= Examples

Practical snippets for `imageio-wmf`. The plugin is used through the standard `ImageIO`
API.

== Read a WMF file

[source,java]
----
BufferedImage image = ImageIO.read(new File("image.wmf"));
----

== Read from a stream

[source,java]
----
BufferedImage image = ImageIO.read(inputStream);
----
