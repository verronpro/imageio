= Examples

Practical snippets for `imageio-emf`. The plugin is used through the standard `ImageIO`
API.

== Read an EMF file

[source,java]
----
BufferedImage image = ImageIO.read(new File("image.emf"));
----

== Read from a stream

[source,java]
----
BufferedImage image = ImageIO.read(inputStream);
----
