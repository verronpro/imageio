= Examples

Practical snippets for `imageio-svg`. The plugin is used through the standard `ImageIO`
API and renders with Apache Batik.

== Read an SVG file

[source,java]
----
BufferedImage image = ImageIO.read(new File("image.svg"));
----

== Read from a stream

[source,java]
----
BufferedImage image = ImageIO.read(inputStream);
----
